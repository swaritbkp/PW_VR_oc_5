# LinkedIn post template (real numbers only; tag Google for Developers and Hack2skill)
Hook: Every event plan goes stale the day someone changes the guest count, a vendor slips, or it rains.
Insight: An event is a project with a fixed deadline. So I used what project managers use (PERT and CPM) and added what they never had: nearby vendors on a map and a Plan B for each.
What I built: Jashn - one visual event graph. Pick a contemporary template, set date and place, find and contact real vendors, hold backups, simulate disruptions, and watch the plan re-balance.
Design decision: the LLM proposes; code computes every number, date and alert; vendors come only from Google Places. Result you can audit.
