# UI rules

- Follow docs/06 and docs/08 and the ref-ui-design skill. Write docs/DESIGN.md before UI code.
- The Event Graph is the hero. One memorable element (Critical Ribbon). Everything else quiet.
- No generic SaaS-card kit, no gradient washes, no emoji as icons.
- Mobile-first at 360px; the canvas becomes a vertical timeline below 480px; bottom dock for the inspector.
- Colour never carries meaning alone. Every chart and the graph has a text alternative and keyboard access.
- Motion: one orchestrated reveal plus motion that answers user actions. Honour prefers-reduced-motion.
- Money in INR en-IN grouping, ranges, estimates labelled. Vendors are "options near you", with Google attribution.
