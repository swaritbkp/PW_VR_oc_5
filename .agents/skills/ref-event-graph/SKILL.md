# Event Graph
Read docs/08. layoutEventGraph returns nodes, edges, lanes, ticks, markers and size; components only draw. SVG, <= 60 nodes, memoised by tasks hash. Critical ribbon from
critical edges, float tails from floatDays, dashed Plan B ring from hasBackup. role=application with a name; nodes are focusable buttons with full labels; arrows follow edges;
Enter opens the inspector; Escape closes; list view always available; vertical timeline below 480px. Motion respects prefers-reduced-motion.
