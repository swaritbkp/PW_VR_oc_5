# UI design process
Ground the design in the subject: celebration, family, North India, a planner who needs calm and clarity. Pass 1 write docs/DESIGN.md: Palette (4-6 named hex with roles), Type (one or two distinct
families with Devanagari and Gurmukhi coverage), Layout (concept + ASCII wireframes), Principles. Pass 2 Critique: if a choice is what you would make for any similar app, change it and say why.
Avoid defaults: cream background + serif + terracotta; near-black + single acid accent; identical rounded cards with the same shadow; gradient washes; ALL-CAPS eyebrows on every heading;
numbered markers for non-sequences; monospace labels everywhere; arrows appended to buttons. Spend boldness in one place (the Critical Ribbon). Floor: 360px, visible focus, reduced motion, AA contrast.
Copy: user's view, sentence case, active voice, specific buttons, errors that say what happened and how to fix it. Screenshot in the Antigravity browser at 360 and 1280 and critique before done.
